# auto-research-skill

Codex skills for a GitHub-mediated research workflow in which Codex executes
and validates project work while a ChatGPT web conversation provides
occasional planning and audit advice. ChatGPT Pro writes its complete review
and proposed plan directly to two pre-authorized checkpoint files; its webpage
reply is only a short commit receipt. Codex verifies that no code or other
out-of-scope path changed before adjudicating the advice.

The repository is private by default. See `skills/auto-research/SKILL.md` for
the workflow contract and `skills/adspower-chatgpt/SKILL.md` for the local
browser interaction boundary.
